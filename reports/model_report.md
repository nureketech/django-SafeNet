# ML-классификатор: есеп

`python -m safenet.ml.train` арқылы жасалды. Модель **train** жинағында оқытылды, `C` гиперпараметрі **val** бойынша таңдалды. test пен gold қолданылған жоқ.

- Белгілер: TF-IDF символдық n-граммдар (2–5, `char_wb`, нормаланған мәтін) + сөздік n-граммдар (1–2) + 3-кезеңнің сандық белгілері (белгілер жалаушасы, есептелген табыс, нысандар саны).
- Модель: `LogisticRegression` (lbfgs, softmax; `class_weight="balanced"`) + `CalibratedClassifierCV(method="sigmoid")`. Калибрлеу бөлінісі `template_id` бойынша (GroupKFold=3).
- Іске асыру (backend): **sklearn** — `sklearn` немесе дәл сол алгоритмнің numpy/scipy нұсқасы (`safenet/ml/linear.py`); sklearn-нің сызықтық модельдері импортталмайтын машинада соңғысы қолданылады.
- Таңдалған `C` = **1.0**
- val macro-F1: **0.910**; accuracy: 0.906
- val қиын негативтерінде «none емес» болжам үлесі: **0.0%**
- Бір жазбаның инференсі (нормализация + белгілер + модель): **9.7 мс**
- Уақыт: белгілерді есептеу 6.65 с, барлығы 11.51 с
